# PAGINA WEB D'UN GRUP MUSICAL
Aquest projecte tractara sobre la construcció d'una pagina web per a un grup musical.
En el nostre cas tractara sobre el grup METALLICA format per: 
·James Hetfield
·Lars Ulrich
·Kirk Hammett
·Robert Trujillo
Metallica és un grup estatunidenc de heavy metal i thrash metal format a Los Angeles el 1981 pel vocalista i guitarrista James Hetfield i el bateria Lars Ulrich. Amb base a San Francisco des del 1983, són considerats una de les bandes més influents i llegendàries del metal, conegudes pels seus tempos ràpids, instrumentals tècnics i música agressiva. Els membres actuals són Hetfield, Ulrich, el guitarrista Kirk Hammett i el baixista Robert Trujillo. Entre les seves cançons més famoses hi ha "Enter Sandman" i "Nothing Else Matters".
